# ColorCorrect
A simple Python-based GUI for color correcting photographs with a faded blue channel

## To compile as a native MacOS app

```
chmod +x build_mac_app.sh
./build_mac_app.sh
```

This creates its own virtual environment and runs PyInstaller. When finished, the app will be located in this directory:

```
./dist/ColorCorrect.app
```

Please Note: I do not own a Windows system and am unable to verify or troubleshoot this application in any version of Windows
